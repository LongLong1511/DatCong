# 🚀 Khởi Động Nhanh

## ⚡ 3 Bước Chỉ Đó

### 1️⃣ Chạy Server
```
Double-click: start-server.bat
```
Hoặc mở CMD:
```bash
cd C:\xampp\htdocs\LAND
python server.py
```

### 2️⃣ Chờ Hiển Thị
```
✓ Server đang chạy trên cổng 8000
→ http://192.168.0.38:8000
```

### 3️⃣ Mở Trình Duyệt
```
http://192.168.0.38:8000
```

---
